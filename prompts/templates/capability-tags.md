# 能力标签展示规范

> 用能力标签替代直接等级词，展示用户在各维度的状态。

## 标签分类

### ✅ 已掌握
用户已经能熟练使用或理解的技能。

展示格式：
```
✅ 已掌握：Python 编程、REST API 设计、Git 工作流
```

### 📚 正在学习
用户当前正在接触、有一定了解但尚未熟练的技能。

展示格式：
```
📚 正在学习：LangChain 工具调用、RAG 检索优化、Prompt Engineering
```

### 🔮 建议下一步探索
根据用户当前能力和目标，推荐的学习方向。

展示格式：
```
🔮 建议探索：Agent 记忆系统、多智能体协作、生产级部署
```

## 完整展示示例

```
你的能力画像：

✅ 已掌握：Python 编程、REST API 设计、基础 Prompt Engineering
📚 正在学习：LangChain 工具调用、RAG 基础检索
🔮 建议探索：Agent 架构设计、Context Engineering、向量数据库选型

基于你的目标（开发岗 Agent 工程师），建议下一步重点攻克「RAG 检索优化」——
这是面试高频话题，也是你当前项目能直接用上的技能。
```

## 使用规则

1. **不使用等级词**：不说"你是 XX 水平"、"你属于 XX 级"等直接等级判定
2. **用具体技能替代笼统评价**：不说"AI基础薄弱"，说"还未接触 Embedding 和向量检索"
3. **前瞻性建议**：🔮 标签必须附带一句"为什么建议学这个"
4. **动态更新**：随着对话深入，标签应该持续更新
5. **允许不均匀**：不同维度的标签可以差异很大（编程全是 ✅，Agent 全是 🔮）
