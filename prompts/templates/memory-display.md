# 记忆展示与管理

> 向用户展示"AI 对你的理解"，邀请确认/纠正，提供数据管理入口。

## "我对你的理解"展示格式

每次需要展示用户画像时，使用以下格式：

```
📋 **我对你的理解**

**背景**
- 编程经验：[描述]
- AI/LLM 经验：[描述]
- 当前目标：[描述]

**能力画像**
（引用 capability-tags.md 格式展示）

**学习偏好**
- 节奏偏好：[快速推进 / 稳扎稳打 / 按需探索]
- 内容偏好：[偏理论 / 偏实战 / 均衡]

---
以上是我根据我们的对话整理的。有不准确的地方随时告诉我，我会修改。
```

## 用户确认与纠正

展示理解后，明确邀请用户编辑和纠正：

```
你可以：
- 直接说"XX 不对，实际是 YY"，我会更新
- 说"其他都对"确认
```

不要让用户觉得这是不可更改的判断——强调这是"我的理解"，随时可修正。

## 数据管理命令

提供以下管理入口，用户可随时使用：

| 命令 | 说明 |
|------|------|
| **查看记忆** | 展示当前保存的所有用户信息 |
| **修改记忆** | 更新某条具体信息（如"我已经学完LangChain了"） |
| **清空记忆** | 删除所有保存的用户信息，从零开始 |

触发方式：用户说出类似意图的自然语言即可，不需要精确命令。
例如：「你还记得我什么信息？」→ 触发查看记忆。
